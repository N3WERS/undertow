# Undertow Android (MVP)

Минимальный порт: главная с чартом, отдельная вкладка «Течение», поиск YouTube, лайки, скачивание и воспроизведение.

- UI: Jetpack Compose, тёмная тема Undertow и иконка из desktop-сборки.
- Главная: hero «Твоя волна», ряды «Мне нравится» и «Скачано», новинки из YouTube Music.
- Библиотека: без вкладок. «Мне нравится» и «История» — полноширинные страницы по 3 крупных трека (до 4 страниц, свайп вправо). «Плейлисты» и «Альбомы» — до 10 уменьшенных карточек со скроллом и кнопками «Все плейлисты» / «Все альбомы». У «Скачано» и «Истории» есть кнопки «Все скачанные» / «Вся история» с полными списками.
- История пишется автоматически при старте трека (до 200 записей), её можно очистить.
- Поиск: треки (фильтр `music_songs`) и альбомы (фильтр `music_albums`).
- Альбом можно открыть из поиска, посмотреть треки и сохранить в библиотеку.
- Сохранённый альбом открывается из библиотеки (обложка), играет и удаляется.
- Поиск артистов (`music_artists`), экран артиста с топ-треками и альбомами.
- Настройки: качество звука (Авто / ~160 / ~96 / ~64 kbps), применение со следующего трека.
- В настройках видны занятое место и число скачанных треков, можно очистить историю.
- В плеере показывается фактический битрейт текущего потока.
- Фоновое воспроизведение: `MediaSessionService`, foreground-уведомление с обложкой/названием.
- В уведомлении кнопки «Предыдущий», «Пауза/Продолжить», «Следующий» — переключают очередь.
- Плейлисты живут внутри «Библиотеки»: создание, добавление из любой строки, открытие, удаление трека и плейлиста.
- Плейлист можно переименовать и выбрать обложку из треков (меню ⋮ на экране плейлиста).
- Очередь: кнопка в полном плеере, текущий трек, удаление и перемещение треков вверх/вниз. Полный плеер открывается анимированно, действия стали крупными иконочными, добавлены shuffle и repeat (очередь/трек); те же кнопки есть в шапке очереди.
- Нижнее меню из четырёх вкладок-иконок без подписей: «Главная», «Течение», «Поиск», «Библиотека».
- Звук продолжает играть после свёрнутого приложения и при выключенном экране; очередь восстанавливается при возврате.
- Плеер: Media3 ExoPlayer, прогресс/перемотка, очередь = текущая выдача.
- Лайки и скачанные треки хранятся локально; скачанное играет без сети.
- Пока нет: плейлистов, текстов, фонового сервиса, Android Auto и DPI.

## Быстрый цикл разработки

```sh
./android/emulator.sh   # видимый эмулятор, не headless
./android/dev.sh        # собрать -> установить -> открыть приложение
```

На Windows без Git Bash: `android\dev.cmd`. Тёплый цикл занимает ~7 секунд; данные приложения (лайки, скачанное) сохраняются.

### Android Studio + Live Edit

Android Studio установлена, проект `android/` открыт и синхронизирован.

1. Нажать **Run** (`Shift+F10`) один раз — приложение запускается на эмуляторе `undertow`.
2. Править Compose-код в Studio.
3. Нажать **`Ctrl+Alt+F10`** (Apply Changes / Live Edit) — изменения применяются без переустановки APK. Проверено на строке «YouTube Music» → «YouTube Music LIVE».

Live Edit включён в настройках; для него нужна именно запущенная сессия из Studio. Если сессия не запущена, используйте `dev.sh`.

## Визуальный стиль

Токены и правила desktop-стиля вынесены в [`STYLE.md`](STYLE.md). Android следует им: тонкий titlebar `Undertow mobile`, фон `#070A0E`, горизонтальные полки, карточки с радиусом 12–13, teal/indigo только как акценты.

Плеер теперь двухуровневый: минимальная нижняя панель (обложка, трек, лайк, скачивание, play) и полноэкранный плеер по тапу — с крупной обложкой, прогрессом, транспортом и доком действий. Очередь открывается из полного плеера и возвращает в него по Back, а сам полный экран закрывается свайпом вниз.

Нижняя навигация — три desktop-подобных пункта с иконкой и подписью в ряд, с активным teal-градиентом и без Material-пилюли.

Плеер оформлен как нижняя панель desktop-версии: прогресс на верхней кромке, белая кнопка play по центру, обложка с рамкой, чип качества и счётчик очереди.

Библиотека собрана из горизонтальных полок: «Мне нравится», «Плейлисты», «Альбомы», «Скачано», «История» (история — внизу). Треки, скачанное и история — полноширинные страницы по 3 крупных строки (высота подстраивается под фактическое число треков), плейлисты и альбомы — до 10 карточек 118 dp. Полные списки «Мне нравится», «Плейлисты» и «Альбомы» — отдельные экраны. Фон приложения повторяет desktop: тёмная база с мягкими зелёно-бирюзовыми и фиолетовыми радиальными бликами; запуск идёт через тёмный splash с той же иконкой, что и desktop, на подобранном фоне без лишней круглой подложки. Главная оформлена в том же ритме: заголовок «Главная», «Чарт недели / Топ 100» с регионами РФ/США/Мир и полным списком, «Новинки», блок топа «Сейчас в тренде» и «Продолжить» из истории. «Мне нравится» и «Скачано» с главной убраны. Поиск получил кастомное поле, underline-фильтры, сетку альбомов и нумерованные строки треков. «Течение» вынесено в отдельную вкладку и работает по логике desktop: 6 семян из любимых артистов, соседи через поиск YouTube Music, пулы по кругу, около 1 своего трека на 20 с зазором 12, второй круг соседей и автодозаправка по 20 треков.

## Сборка

Нужны JDK 17 и Android SDK 35.

```sh
cd android
./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

## Ограничения MVP

- Уведомление управляет очередью; при полностью убитом процессе воспроизведение останавливается.
- Очередь — это текущая выдача поиска или главной.
- Яндекс и импорт библиотеки не подключены.
- Скачивание идёт напрямую с googlevideo, поэтому может быть медленным.

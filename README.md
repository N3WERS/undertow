# Undertow

Музыкальный клиент для Windows/Andoid

Основа — YouTube Music: поиск, альбомы, артисты и звук. Яндекс.Музыка
подключается по желанию, если у вас есть токен и активный Плюс.

## Что можно делать

- Слушать лайки и историю, собирать свои плейлисты.
- Искать треки, альбомы и исполнителей в одном месте.
- Открывать страницы артистов и альбомов, смотреть новинки любимых артистов.
- Включать радио артиста или «похожее» на трек — очередь не кончается.
- Запускать «Течение»: бесконечный поток по вайбу библиотеки, можно по жанру.
- Читать текст песни с подсветкой текущей строки, если он есть.
- Слушать без пауз между треками и с выровненной громкостью.
- Обновлять приложение из настроек: проверка нового релиза, скачивание и установка без похода на GitHub.
- Управлять воспроизведением из Windows: медиа-клавиши, кнопки на панели задач,
  системный оверлей «Сейчас играет», ссылки `undertow://` и меню Пуск.
- Искать всё через `Ctrl+K`: треки, артистов, альбомы, плейлисты и действия.
- Искать, сортировать и выбирать треки в библиотеке, убирать дубли и скачивать пачкой.
- Ставить альбомы и плейлисты в очередь загрузок, ставить её на паузу и повторять ошибки.
- Запускать «Течение» от трека, альбома или плейлиста и сохранять поток в плейлист.
- Открывать новые артисты из «Течения» и исключать нежелательных навсегда.
- Пользоваться компактным мини-плеером с очередью и перемоткой.
- Показывать текущий трек в Discord через Rich Presence — Client ID уже встроен, нужен только тумблер.

## Установка

1. Скачайте `Undertow-Setup-....exe` со страницы Releases и установите.
2. Запустите Undertow. Встроенный `yt-dlp` уже лежит внутри установщика,
   Python и отдельная настройка не нужны.

Установщик ставит приложение в `Program Files` и службу обхода DPI, поэтому
Windows запросит права администратора.

Установщик не подписан, поэтому Windows один раз покажет «Windows защитила ваш
компьютер». Нажмите «Подробнее» → «Выполнить в любом случае» — для личной
сборки это нормально.

## Горячие клавиши

- `Ctrl+K` — поиск по всему приложению и действия.
- `Ctrl+F` — поиск по библиотеке.
- `Пробел` — пауза или продолжение.
- `Alt+→` / `Alt+←` — следующий и предыдущий трек.

## Если YouTube открывается медленно

В «Настройках» есть тумблер «Обход DPI для YouTube». UndertowDPI сам
перехватывает TLS-рукопожатие к доменам YouTube и Google и делит его на два
TCP-сегмента; остальной трафик не трогается.

- Движок и WinDivert лежат в установщике, в `resources\zapret`.
  Внешние папки и отдельные утилиты не нужны.
- Установщик ставит службу `UndertowDpi` от SYSTEM. Включение и выключение
  обхода идут через неё, без повторных запросов UAC.
- Служба сама выключает обход, когда Undertow закрывается.
- Права администратора нужны только при установке или обновлении приложения.
- Без обхода приложение работает как обычно.


## Про Яндекс.Музыку

Без токена приложение работает только с YouTube. Это нормальный режим, ничего
не ломается: страницы артистов, альбомы, новинки, радио и «Течение» тоже
берутся из YouTube Music.

Если хотите подключить Яндекс:

- Нужен токен от официального клиента Яндекс.Музыки. Он вставляется в
  «Настройки» внутри приложения, в чат или файлы его писать не надо.
- Нужен активный Плюс. Без него Яндекс полностью выключается: приложение не
  показывает 30-секундные превью и не притворяется, что трек играет.
- С Плюсом звук берётся из Яндекса для тех треков, которые там есть, — это
  MP3 320 вместо Opus ~160 с YouTube. Остальные играют с YouTube. Каталог,
  обложки и страницы при этом всегда из YouTube Music.
- Токен хранится только на этом компьютере, зашифрованным, и никуда не
  отправляется.
- Импорт лайков и плейлистов из Яндекса тоже работает только с Плюсом.

## SoundCloud

В поиске есть отдельная вкладка «SoundCloud». Это дополнительный источник,
не замена каталогу: треки, исполнители, обложки и альбомы по-прежнему из
YouTube Music, а SoundCloud даёт свои загрузки и ремиксы.

- Вход не нужен: используется публичный API и временный `client_id` со
  страницы SoundCloud.
- Звук приходит HLS-плейлистом, его играет `hls.js` прямо в приложении.
- Офлайн-копия работает: приложение скачивает HLS по сегментам и склеивает
  их в один `.m4a`. Такой файл играет без сети и без SoundCloud.

## Если собирать самому

```bash
npm install
npm run dev        # запуск с горячей перезагрузкой
npm run dist       # установщик в release/
```

Для сборки нужен Node.js 22 или новее.

## Чего пока нет

- Синхронизации библиотеки между устройствами.
- Подписи установщика: SmartScreen будет ругаться, это ожидаемо.
- Автообновления `yt-dlp`: встроенный бинарник можно заменить на свежий
  вручную, если YouTube что-то поменяет.
